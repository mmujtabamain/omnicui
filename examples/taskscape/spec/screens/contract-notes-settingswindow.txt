notes: |
  Based on: the inventory settings-general.json (regions, widgets, states), features-settings-general.txt, the F10 detail records as cited by the two drafts, decisions 2, 16 and 19, the contract format and the library list. No source code was read.

  Props, as the harness must act on them:
  - dataset (standard | empty | nolists | long, default standard): loads that demo data set into the local SQLite database before mounting. Every test uses the default; the window shows no task data.
  - motionSignal (none | lowPower | systemPrefers, default none): reports that OS signal to the app's motion handler, as macOS would. lowPower = Low Power Mode on; systemPrefers = macOS Reduce Motion on. Only the two macOS tests set it. A live change mid-test is not possible.
  - storedTheme (none | system | light | dark, default none): writes the value into the settings store before mounting, so the window opens with it as the value at open. none leaves the store empty, so every setting starts at its default. Needs harness seeding support; if the harness cannot seed, drop the storedTheme test.
  - The window always mounts with General selected and an empty search query.

  Events:
  - settingChanged: emitted on every setting write, including each write a discard makes. Discard counts assume one write per changed setting; the order of discard writes is not asserted.
  - windowClosed (reason: escape | shortcut): emitted once per close. times 0 means the window did not close. Proposed event names.

  Left out, with reasons:
  - Close, minimize and zoom: the OS draws them (decision 2). The OS close button, minimum size and resizing are OS behaviour and have no step.
  - Opens once, and a second request focuses the window: only the app shell can count or focus windows; no part here shows it.
  - Title-bar drag: drag acts only on slider parts.
  - Window fade-in (F10-001): no user step starts it; the harness mounts the window.
  - Scroll to top on section click (F10-005): no scroll-position field.
  - Dimmed tabs while searching (F10-016), focus outline as a visual (F10-010; covered by the focus screenshot), changed-group dot (F10-034), section header rule (F10-035), section icons and order (F10-002): visual or not expressible with the fields. Fixed section order is not asserted.
  - Tooltips: no text part.
  - F10-019 (editing a scoped query returns to results in every section): needs matches in another pane; not tested.
  - F10-021 and F10-022 (Shortcuts intro hidden while searching): belong to settingsshortcuts; General has no intro.
  - F10-026 (Escape and Cmd or Ctrl F swallowed while recording) and rebinding discard: settingsshortcuts.
  - F10-030, F10-031, F10-032, F10-033 (persistence across launches, write failures, unreadable stored values, baseline across reopening): one headless mount on one data set cannot produce them. The within-session baseline and the stored value at open are tested instead.
  - F10-036 and F10-064: not covered by any test here; the drafts give no reason, so they stay out until checked.
  - Live change of the macOS signal (F10-062): no step can change an OS signal mid-test.
  - Web-only items (sign-in, account menu, modal settings, browser Escape, Cmd or Ctrl F override) and web decisions 15, 17 and 18: not desktop behaviour.
  - Pane contents (the Theme, Reduced motion and Show completed rows, footnotes): checked here only for the window-level parts; their own behaviour belongs to settingsgeneral.
