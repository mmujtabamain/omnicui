## New
- **0.2.1's changes ship here.** Its release stopped at the tests, so 0.2.1 was never published: `check --test`, `--failed` and `--serial`, times per test, start-up progress, `exclusive` targets, "not measured" keyboard tests, target `keys`, masks and optional parts, `do:` actions, scale traces, part clips, round-trip motion and `selected` are all in 0.2.2. See notes/0.2.1.md.
- **A smoke test** (`scripts/smoke.sh`) builds the release files and uses them as a project does: the binary's version, help, contracts, targets, a check with two fake targets that passes, one that fails, `--failed`, and the source tarball built the way a vendoring project builds it. It runs on every merge request and in the release job before anything is published.

## Changed
- **The Go tests and the smoke test run on every merge request**, whatever it changes, so that what the release job runs on main has always passed first.

## Fixed
- **Each target's time is printed whatever the machine's speed.** It was printed only when some test took a second or more, so a test that checked for it failed on a fast machine.
- **A test of exclusive targets** no longer depends on two processes starting within a few milliseconds of each other.
