## New
- **Four pixel measures.** Each screenshot pair is measured by area, strength (recoloured pixels), shift (displacement) and spot (the worst 24×24 px spot), each with its own threshold (defaults 30%, 28%, 8 px, 2%). The console and report.html show a table per pair, and the worst spot is put down to a part.
- **Motion from clips.** A recorded clip becomes its visual progress and is compared like a trace under `thresholds.motion` (40 ms), so fades, blurs and colour changes are compared on every target. report.html plays every target's clip together, lined up at the input. Clips are lossless animated PNGs.
- **Opacity traces** (`trace: { part, property: opacity }`), `allCombinations: true`, and per-viewport `props`.
- **`keyboard: true`.** For every button, switch and checkbox, Enter and Space (per role) must do what a pointer press does.
- **The render check** (`probe`): a target that advertises screenshots draws a known picture first, or its screenshots are off for the run, with the reason. `omnicui targets` shows it.
- **`bounds`**, the `visible`, `role` and `focused` fields, and a warning when a test reads a part that has no size on screen.
- **The busy hook:** adapters wait for an app that says it is still loading (web `window.omnicuiBusy`, egui `Mounted::busy`, JavaFX `Component.BUSY`).
- **`check --fail-on warnings|pixels|timing|visibility`**, a progress line per test, `omnicui compare a.png b.png` and `omnicui help contract`.

## Changed
- **`thresholds.pixels` is now `area`**, and the old name is refused with the new spelling.
- **`record` replies `{frames, inputs, held}`;** a bare list of frames is still accepted.
- **Contract errors say the expected form,** for example ``write `cardNumber` `` for a part named `card-number`. A threshold far below its default warns, and timeouts name the `target.yaml` setting to raise.
- **Repeated failures are printed once.** A linked target folder is followed, and its stub generator isn't run.

## Fixed
- **Web static server:** the web app's and the web target's servers no longer crash on a missing file.
- **Web textbox:** a text box's text is read from its value.
- **Chromium dying:** the web adapter exits, so the target is broken once instead of failing every test.
- **JavaFX:** sizes Monocle's headless screen to the largest viewport, and writes recorded frames off its UI thread.
