## New
- **`omnicui check`.** Runs every contract's tests on every target over JSON-RPC 2.0, compares their screenshots (the share of the drawn area that differs) and their motion (against the contract's CSS timing and each other), and writes `results.json` and `report.html`.
- **The rest of the command.** `targets` (what each target can do on this machine), `contracts`, `stubs`, `add` and `remove`, `version`; `--project`, `--out` and `--require target:capability`. Ctrl+C or SIGTERM stops every adapter it started.
- **A reference project.** Three apps (React, egui, JavaFX) with the same counter and switch, their targets, and `run.sh` to set up, run the apps, check, demo and test.
- **The specification** in `docs/SPEC.md`, with the evidence in `docs/verification/`.
